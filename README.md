# CapSongs GDI para Android

Downloads, biblioteca local e karaokê com letras sincronizadas por verso.

## Download

[Baixar APK de testes — Android.2](https://github.com/gasparinidi-ui/capsongs/releases/download/v1.6.1-android.2/CapSongs-GDI-1.6.1-android.2-preview.apk)

[Ver versões e arquivos](https://github.com/gasparinidi-ui/capsongs/releases)

Requer Android 8.0 ou superior. O APK inclui ARM 32 bits, ARM64 e x86_64.

## Instalação

Baixe o APK no celular, abra o arquivo e confirme a instalação. Se já usa a versão Android.1, instale como atualização, sem desinstalar, para preservar a biblioteca.

## Estado da versão

Esta é uma versão de testes. Android.2 incorpora yt-dlp 2026.10.21 e permite atualizar o motor em Ajustes. Foram aprovados 19 testes unitários; o reteste dos downloads no celular permanece pendente.

Antes de desinstalar, exporte músicas e letras importantes: a desinstalação remove os dados internos do aplicativo.

## Código-fonte e integridade

O projeto Android e os códigos SHA-256 acompanham a publicação em Releases. O pacote não contém músicas, cookies pessoais ou chave de assinatura. Os avisos e licenças dos componentes estão incluídos no código-fonte e no aplicativo.
